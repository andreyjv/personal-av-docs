Connectivity Explain

First attach

Lexicon

Activate is a Service plan / subscription decision. Enable is a PIN, STK, or module feature switch. Attach is radio / packet attach on the module. A System in the API is not the same object as a SIM. Operator prose uses Service plan; the API keeps offer / offerId — map that once, do not rename the contract.

SW Advanced module prerequisites​

If you are using an SW Advanced SIM, in order to get the SIM to function properly with a given module:

  • The SIM Application Toolkit (STK) is active on the module
  • Set the module in automatic network selection
  • GPRS/Packet data auto attachment mode must be active on the module for the SW Advanced SIM

SW Essentials and Enhanced carrier connectivity SIMs have no specific module requirements.

First start-up scan​

Upon first start-up of the device with an SW Advanced SIM, the device must wait until the network scan is complete with all configured roaming agreements: order of magnitude is 15 minutes.

During this period:

  • No data, SMS or Voice communications must be attempted
  • Reboot shall be avoided or the first start-up scan will have to start over

For following start-ups:

  • SW Advanced SIM: network attachment shall take around 15 seconds
  • Tailored SIM: network attachment may take 1 to 2 minutes depending on the module and the network conditions

PIN​

The PIN code is disabled by default in the SIM card. It can be enabled if needed; ask the PIN code to your support contact.

Sequence​

Inventory → Activate (Service plan + lifecycle) → APN on module → radio attach.

Activate does not mean the module is transmitting.
