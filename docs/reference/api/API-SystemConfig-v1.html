System Configurations General f General Information Operations f System Operations Alert Application Gateway Settings Dataset Label Zone Operator Offer & Options System Configurations Administration f Company Partner Profile User Subscription f Subscription Ordering f Contact Order Product Reference System Configuration Overview Fields JSON A system configuration is an entity used to identify the software elements (application, firmware) that have to be defined on the device. A system configuration contains a set of applications indicating the order of installation between software elements. A system configuration is identified by a name. Read only fields are computed by AirVantage and can only be seen on response fragments sent by find , create , or edit requests. Field Description Read Only Type uid System configuration's unique identifier. true uid name System configuration's name. false string applications List of applications. false object array This is a complete representation of an System Configuration.
