How to Create Fleet Management Groups

:::note Edition almsc · imported from live Hugo on 2026-10-07. Guides stay latest. Original page. :::

How to Create Fleet Management Groups Fleet Management Groups A system can only belong to one Fleet Management Group. Fleet Management Group membership cannot change unless you manually move the device from one group to another. Fleet Management Groups are best suited to keeping your routers updated with common settings (using linked configuration templates) and software. This is done by setting group policies (rules) that define what software and settings that routers in a group can run. Creating Fleet Management Groups Creating a Fleet Management Group includes these steps: Adding and naming the Group Adding rules to the Group. You can use rules to apply consistent configurations across devices in your group. Heartbeat –Sets the AirVantage check-in status report frequency for all devices in the group Install Firmware –Installs the selected operating system firmware version on the selected device model. Create one Install Firmware rule for each device model in the group. Apply template –Applies the selected device template on the selected device model. Create one Apply template rule for each device model in the group. Adding Devices (Systems) to the Group Adding users to the Group To create a new Fleet Management Group: Go to Configure > Groups . Select the type of Group to create: Fleet Management . Click Add group… . The New group panel appears. If required, under Parent , click to select a Parent Group for the new Group. Enter a Name for the Group. Click Create (or click Revert to start over). Now that you’ve created the Group, you can start adding rules. To add Group rules: Click Add rule… Select one or more rules. After selecting one instance of each rule, the new group panel will appear as below. Configure the selected rules. For more information, see Fleet Management Group Rules . Optional: Click the up/down buttons to change the order of the selected rules. When rules are applied (see Applying Rules ), they are applied in order, top to bottom. Click to remove a rule. Click Save . To add devices to a Group: Go to Monitor > Systems . Select the systems you want to add. Click More general & life cycle actions and go to Groups > Add to groups . In the Systems > Add Group panel, click Fleet management . Select the desired Group. Click Add . On the confirmation message, select an option: Add and apply rules–adds the devices and applies the rules immediately (update the device firmware, for example) Add only–adds the devices without applying rules Cancel–return to the group selection panel Creating a Child Group The number of parent/child group levels is limited to 10. For example: Parent (level 1) Child/Parent 1 (level 2) Child/Parent 1.1 (level 3) Child/Parent 1.1.1 (level 4) Child/Parent 1.1.1.1 (level 5) Child/Parent 1.1.1.1.1 (level 6) Child/Parent 1.1.1.1.1.1 (level 7) Child/Parent 1.1.1.1.1.1.1 (level 8) Child/Parent 1.1.1.1.1.1.1.1 (level 9) Child 1.1.1.1.1.1.1.1.1 (level 10) Child Fleet Management Groups are empty when created, and you must manually add rules and devices to them. To create a Child Group: Go to Configure > Groups . Select the type of Group to create: Fleet Management . In the desired Parent Group’s Name column, click Add . The New group panel appears, showing you the parent Group. Add a name for the new child Group, and configure it as described in Creating Fleet Management Groups above. Fleet Management Group Rules Heartbeat The Heartbeat rule sets how often the router checks in to AirVantage and sends its default status report. The default setting is 15 minutes. This is also the minimum setting, but you can set the Heartbeat to longer periods in units of minutes, hours, days and weeks. This rule is applied to every device in the group. Install firmware Applying the Install firmware rule updates routers with a selected firmware release. Each router model in the group needs to be added to the Install firmware rule. To configure the Install firmware rule: Click Add device model… . Select the desired AirLink router model. Click Select a firmware… Select the desired firmware version. If you have other router models in the Group for which you want to install firmware, return to step 1. Click Save . Apply template Applying the Apply template rule updates routers with a selected device template. For more information, see How to create and apply a template . Each router model in the group needs to be added to the Apply template rule. To configure the Apply template rule: Click Add device model… . Select the desired AirLink router model. Click Select a template… Select the desired template. If you have other router models in the Group to which you want to apply templates, return to step 1. Click Save . Ensure that the templates that you select are compatible with any Install firmware rules selected. The device names and firmware versions in the firmware names and the template names should match. Check Compliance Under the Compliance tab, you can check which devices are complying with the Group rules. For example, the Compliance tab indicates which devices are not running the selected firmware version or have not had the selected template applied. Devices’ compliance status is not automatically reported when you add devices to a Group. Click Check Compliance to generate device compliance status for a Group. The compliance results are also summarized in the main Groups table, in the Rule compliance column. If any devices are not compliant, you can: change the Group rules. When you save the change, you can apply the updated rules to the devices apply the group rules to bring the device into compliance. See Applying Group Rules below. Applying Group Rules To apply Group rules: Select the Group in the main Groups table. Click Actions > Apply group rules . In the Groups panel that appears, select the rules to apply. You do not need to apply all the Group rules. Click Apply . You can apply rules to only one Group at a time. Rules are applied in order, top to bottom. In the example above, the device will receive a firmware update, then have a template applied. Firmware rules may fail to apply because the devices are running much older firmware versions that require an interim upgrade before upgrading to the target version. A template application may fail because the template is not compatible with the firmware version running on the device. Ensure that your Install firmware and Apply template rules are using the same firmware version. Operations may fail if the device does not check in within the timeout threshold Add Users to a Group Administrators and users with “Groups Write” permission can add users to a Group. You can add users from your company and any partnered companies. The process of adding users also includes adding profiles to those users to control who can view or edit the Group, and control what users can do to the systems within the Group. Before starting, confirm that your users exist (see Administration > Users ) and that the profiles for those users are configured (see Administration > Profiles ). For more information, see Administration and Managing Profiles . To add users to a Group: When editing a Group, click Access . In the Access tab, click Add users… . In the Add users panel, under Company , select the company from which you want to add users. Click Filter… to search for a specific partnered company. Under Users , select one or more users. Click Select users… to search for a specific user. To select more users from a different company, return to Step 3. Under Profiles , select one or more profiles that will control what the users can do within that Group. For example, Groups Read or Groups Read/Write . In this example, you could also select Configuration Management so that the users can configure systems in that Group. Common profile combinations: “Groups Read” + “Systems View” for view-only users “Groups Read/Write” + “Systems View” + “Operations” for full management Click Add . Verify that the users now appear in the Access tab with assigned profiles. The next time those users log in, they will be able to view only the Groups to which they have access and be able to take actions according to their assigned rights. Users require both Groups Read and Write access to view Groups and modify them. User access can be affected by whether a Group is a parent or child Group. Users added to a Group will have access to that Group’s child Groups using the same profiles they were assigned in the parent Group. You can add additional profiles for a user in the child Group. However, if a user wants to modify a child Group’s definition, then they must have Group Write permission in the immediate parent Group. Deleting Users To delete a user: When editing a group, click Access . In the Access tab, under Actions, click . Click Confirm . The user loses access immediately. You cannot delete a user or remove a profile from the user if that user or profile exists in a parent Group. If a user has access via a parent Group, remove them from the parent Group instead. Edit Groups To edit Groups, you must have Groups Read/Write access, AND the Group cannot be a top-level Group. Top-level Groups can be edited only by System administrators. To edit an existing group: Go to Configure > Groups . Click the desired Fleet Management group. The group details appear. If you have the required group access rights, you can edit the following options: Edit the group Name Edit or add a Rule If you have the required group access rights, you can edit the Group users. Click Save or click Revert to cancel any changes.
