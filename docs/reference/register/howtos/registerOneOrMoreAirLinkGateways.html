How to register one or more AirLink gateways?

Matching results How to register one or more AirLink gateways? If you are an AirLink gateway user, the first step to using AirVantage is to register your devices in the system. Follow the steps below to learn how to register one or more AirLink gateways. 1 / Register 2 / Import Step 1: Register Gateway Before you can begin managing your AirLink gateways with AirVantage, you must first follow the device registration procedure. Registering a few devices can easily be done via the web interface. Alternatively, to register a large number of devices you can bulk import their details in a CSV file. Display the Register page Let’s go to the Register page. Click the Register widget on the Start page (if displayed), or the Register tab from the top menu bar. Enter gateway details Suppose that we have an AirLink MP70 to register. Enter the serial number. AirVantage identifies the device type. After you enter the serial number, AirVantage also identifies the device operating system and configures the registration window accordingly. An IMEI/ESN field appears for ALEOS devices, and a Registration Code field appears for AirLink OS devices. If AirVantage does not identify your system type (or misidentifies your system type) when you enter the serial number, click Select system type in the top left corner. The device catalog appears,and you can select your system type from there. Your gateway’s serial number can be found in two different ways: The serial number is printed on the gateway label. Note, you’ll need to remove the “dash” from the serial number (if present). The IMEI is also printed on the gateway label. You’ll need this number to register an ALEOS gateway or router. Gateways and routers running AirLink OS require you to enter a Registration Code, which is printed on the device label. Or you can find an ALEOS device’s serial number in ACEmanager by selecting the device’s Status > About page to view the Serial Number field (known as Global ID in older versions of ALEOS). Registering an ALEOS device Once you have entered the serial number and IMEI, give your device a name in the Name field, and enter the ACEmanager password (devices using MSCI only). As an optional step, you can select whether to put the device into maintenance mode at registration. If you change Activate Device to OFF, the device is placed in Inventory after registration. The system will activate after 60 days unless you manually activate it. For activation instructions, see How to activate a system? Registering an AirLink OS device Once you have entered the serial number and registration code, give your device a name in the Name field. As an optional step, you can select whether to put the device into maintenance mode at registration. If you change Activate Device to OFF, the device is placed in inventory after registration. The system will activate after 60 days unless you manually activate it. For activation instructions, see How to activate a system? Completing Registration Click the Register button to start the registration. AirVantage will notify you once the operation has completed, and you will see your gateway at or near the top of the Device Catalog. The list contains all the devices that have been registered with AirVantage. They can be sorted by their Synchronization status. For example, to show unsynchronized devices, click the blue icon: Your newly added gateway will be shown as unsynchronized. Initiate communications Connect your gateway. All gateways are pre-configured to automatically connect to AirVantage on each reboot. Devices will also check in with AirVantage on a set frequency, which is once per day by default. After the device’s first communication, click its Refresh button to verify the synchronization status. If the status icon becomes green, it means your system has been synchronized. Your device can now be monitored and configured from AirVantage. Click the Monitor the system icon to start. Step 2: Import Systems If you have a lot of devices to register, it is simpler to perform a bulk registration. Please note that you can only register one class of device (AirLink MP70, for example) at a time. Ensure that you start with a template downloaded from the registration page of the same class of device you want to bulk register. Bulk registering ALEOS devices Create CSV file Click Import a list on the registration details page. An Import Systems dialog box opens. Download the CSV import file template by clicking Download template . The gateway serial number and IMEI are the only fields in the spreadsheet that must be filled in. If you only have your IMEIs, contact your reseller or Sierra Wireless; they can get a serial number conversion for you. If you use the AirLink Raven, PinPoint or MP gateways, you’ll be required to enter the IMEI or ESN value instead. It is a best practice to give your device a Name. We recommend assigning a unique one to each device to simplify identification. The MSCI (host) and Communication (password) fields are used only if you want to enable server-initiated communication if you are using MSCI. However, we do recommend device-initiated communication. If you want to use server-initiated communication, see How to set up server-initiated communications for AirLink gateways for more details. Bulk registering AirLink OS devices Create CSV file Click Import a list on the registration details page. An Import Systems dialog box opens. Download the CSV import file template by clicking Download template . The gateway serial number and registration code are the only fields in the spreadsheet that must be filled in. It is a best practice to give your device a Name. We recommend assigning a unique one to each device to simplify identification. Import CSV file Once you’ve finished compiling the import file, go back to the Import dialog box. Click Select a CSV . Browse and select the import .csv file. The Import dialog box alerts you if any information in the .csv file is missing or incorrect (as shown here). Select Specify reference firmware if you want to update your devices with a specific firmware during registration. Select Send email notification when operation completed to receive a confirmation email once the system is registered. To pre-configure the devices during registration, click Pre-configure Systems . For more information about pre-configuration, see How to register systems with an initial configuration Click Import . You will see your list of newly registered devices added to the Register page. They will normally synchronize with AirVantage after their first communication. If they don’t manage to synchronize, please verify the AirVantage settings in ACEmanager as explained above.
