Connectivity How-to

Activate SIMs

Pick a Service plan and activate the subscription. Shipped SIMs stay in Inventory until you do this.

Lexicon

Activate is a Service plan / subscription decision. Enable is a PIN, STK, or module feature switch. Attach is radio / packet attach on the module. A System in the API is not the same object as a SIM. Operator prose uses Service plan; the API keeps offer / offerId — map that once, do not rename the contract.

Before you begin​

SIMs available in your account (Inventory means not yet activated)
A Service plan suitable for the SIMs you select
Permission to activate
For an Enhanced Carrier Connectivity Verizon SIM, an IMEI on the system before you click Activate

Assign an IMEI on a Verizon SIM​

An Enhanced Carrier Connectivity Verizon SIM needs an IMEI on the system before activation. Without it, activation returns an error.

1

One system

In Monitor > Systems, select the system and click Edit in the More menu. You can also click Edit on the system details.

Click + (Create a new Gateway). In Create gateway, enter the serial number and the IMEI, then click Create.

2

Many systems

In Monitor > Systems, filter the list and check the systems. Open More, then Import & Edit.

Under Step 1: Get template, download the template. Fill the GATEWAY[IMEI] column. Keep the editor from turning ICCIDs into numbers. If the file will not import, use How to edit csv files on the current manual.

Under Step 3: Finalize, import the file and click Import & Edit.

Activate​

Activate the service on the SIMs by selecting a Service plan. The control in the dialog is labeled Offer. That is the Service plan. Radio attach happens after the APN is configured on the module.

1

Sign in

Sign in at the host for your region: https://na.airvantage.net/accounts or https://eu.airvantage.net/accounts.

2

Open connectivity

Follow the Manage my connectivity link.

3

Select SIMs

Select the SIM cards you want to use. A few SIMs use this same Activate button. For hundreds or thousands, filter the list first. That procedure is Activate many SIMs.

4

Click Activate

Click the green Activate button in the list header.

5

Pick a Service plan

In the dialog, select a Service plan, then click Activate. You can enter an email address to be notified when the operation finishes. Advanced options can schedule the activation for a later time.

What Activate does

Picking a Service plan moves the subscription out of Inventory. PIN, STK, and radio attach are separate steps. Progress is in the Operations widget. Open the operation to see the status of each SIM. A large selection can take a few minutes per SIM.

Test ready starts when you activate the SIM on a Service plan that includes Test ready mode. What each status means is on States and operations.

When the order arrives​

SIMs in a shipment are not activated. From the start page, open the order in the Latest SIM Orders widget.

1

Open the order

On the order details, the ICCIDs widget lists the ICCIDs for that order.

2

Open the filtered list

Click Manage My Connectivity. The list is filtered by that order ID. You can add the Order ID column from the grid configurator at the top right of the system grid.

3

Activate the selection

Select the SIMs. Use the select-all checkbox for the whole order, or select a subset. Click Activate, pick the Service plan, and click Activate again. Follow the operation in the Operations widget.

Order IDs start with SO-. You can reach the same list from Monitor by filtering on Order ID.

Activate many SIMs​

Only a SIM in Inventory can be activated. Click the Inventory segment of the State chart to filter the list to that state.

You can combine filters. A label filter can sit on top of the state filter. An ICCID filter can keep ICCIDs that start with a prefix.

To activate every SIM from one order, filter Order ID as above, select all (or a subset), and click Activate.

When you need a sort the grid does not offer, export the rows and label the ones you will activate:

1

Export

Select the range (an order, or a label). Click More > Export Data and choose the fields. On Operations, open Actions > View for the completed Export System(s) data operation and retrieve the CSV.

2

Sort outside AirVantage

Open the CSV in a spreadsheet as comma-delimited text. Keep subscription IDs as text so they are not rewritten as numbers.

3

Label the SIMs you will activate

In AirVantage, use Change Labels. Filter by ICCID/ESN and paste the identifiers from the spreadsheet. Apply the label, filter the grid by that label, select the rows, and click Activate.

Change provisioning options​

Activation applies the default options of the Service plan. Provisioning options are the permitted services and the roaming configuration. You can change them afterward. The options you are offered are the ones compatible with that Service plan. To add an option that is not in the list, contact Semtech support.

1

One system

Open the system details to see the assigned options. Add or remove them from the system details, or select the system in Monitor > Systems and use Change provisioning options.

Click the list to add an option. The current manual’s example sets the roaming zone template to RZT - EU so only EU+ countries are allowed. Remove an option with the x beside it. For a roaming template, pick another template.

2

Several systems

Select the systems and click Change Provisioning Options. The (+) list is options you can assign. The (−) list is options assigned to every selected system; pick one to remove it. The roaming template dropdown applies one template to the selection.

The current manual’s example selects systems on the 2Mb EU Bundle, sets RZT - EU, and can remove Voice - MT in the same operation.

3

Run the change

Advanced settings can set a schedule, a timeout, and an email when the operation finishes. Click Change Provisioning Options. The change can take several minutes. Status is in the Operations widget.

Filter the system list with Provisioning option and Provisioning option not. The current manual filters on a DATA APN option, and on systems that do not have the SMS option. Labels and the other filters can narrow that list, including every system on one Service plan.

If circuit-switched options are enabled, LTE-only networks such as Verizon, Sprint, and KDDI are not available for roaming. Data-only options extend coverage to those networks. The option label then shows LTE - Data Only.

Smart Connectivity for LPWA​

Two settings matter for Cat-M1. A dedicated LPWA APN lets the Semtech network tolerate longer sessions and support PSM and eDRX when the partner allows it. A dedicated LPWA roaming template keeps the SIM on official Semtech Cat-M1 coverage, with 2G as fallback.

Use the APN shown on the system (System Info, and the APN table). The roaming template for LPWA Cat-M1 is RZT - WORLD LPWA. For Cat-1+, 3G, and 2G the manual recommends internet.swir, which is the documented example in the APN section below, and the template RZT - WORLD COST LIMITED, or a more restrictive template. A fleet that is only Cat-M1 may already have these settings.

A private APN is arranged with your Semtech account manager.

1

Open the systems

Sign in at the regional host above. Follow Manage my fleet, then Monitor > Systems. Filter by IMEI, name, ICCID, or another field, and tick the systems.

2

Set the template

Click Change provisioning options. Add the LPWA APN shown for that system and select RZT - WORLD LPWA. Click Change Provisioning Options.

3

Match the module

Set the module APN to the authorized APN on the system.

Custom static IP​

This applies when the account has a private APN with custom static IP allocation. Contact Semtech technical support or your account contact to arrange that allocation.

Set the requested IP address before you add the private APN option. If the option is added first, activation or the add-option operation fails.

1

One system

In Monitor > Systems, select the system and click Edit in the More menu, or click Edit on the system details. Set the requested IP address. That address is used when the private APN option is added.

2

Many systems

Filter and check the systems, then More > Import & Edit. Download the template, fill SUBSCRIPTION[REQUESTED IP], and keep the editor from transforming ICCIDs. Import the file and click Import and Edit.

3

Check the address

From the grid configuration icon, add the Requested IP Address column. The value is visible before it is attributed, including while the system is still in Inventory or before the private APN option is added. After that option is active, Requested IP Address and IP address show the same value.

4

Add the private APN option

Activate the system if the Service plan adds the private APN by default. Otherwise, in Monitor > Systems, click Change Options and add the private APN configured for the account. Remove the dynamic APN option in the same change. The APN value is the one on the system.

For accounts with the static IP option, the system grid can show an IP address column. System Info can also show the IP address, the PUK code, and the authorized APNs. APN values and SMS short codes are on the APN table.

From Inventory​

These actions are in the Inventory activity. They are separate from the green Activate button under Manage my connectivity.

Activate or synchronize a subscription​

Open Inventory > Subscriptions.

If the SIM is inactive at operator level, select it and click Activate (in the action bar, or in the Actions column). Fill the required fields in the Activate window. The window lists those fields.

If the operator has already activated the SIM, click Synchronize and fill the Synchronize window. Using Activate on a SIM the operator has already activated returns an error.

The subscription then shows as active in the subscription list.

Create a subscription​

Open Inventory > Subscriptions and click Create. Enter an identifier (ICCID or ESN), a network identifier (IMSI), and a mobile number, as the operator requires. Select an operator and an operator account. Click Create.

After the subscription is on a system, you can show the mobile number as a Phone Number column on the systems table.

Import subscriptions​

Open Inventory > Subscriptions and click Import. The window can download a template. Provide a CSV and click Start. Comma and semicolon are both accepted.

The header names the columns. Provide at least one of IDENTIFIER (ICCID or ESN), MOBILE NUMBER (MSISDN), or NETWORK IDENTIFIER (IMSI). OPERATOR is required. IP, OPERATOR ACCOUNT, and LABELS are optional. Separate several labels with |.

Activate a system for monitoring​

Open Inventory > Systems, select the systems, and click Activate. Confirm Activate in the dialog. A tick box can activate the subscription at the same time when a carrier account is configured for subscription management. The system is then in the ready state.

Selecting more than 100 systems applies a label automatically. You can delete or change that label from the systems list in Inventory or Monitor, or from Labels under Configure.

Change the Service plan on a device​

In the combined account you can change the Service plan on one or more devices. The toolbar control is Change offer.

Select the devices and click Change offer. Choose the Service plan in the dropdown. The dialog reports when the change affects the device subscription. Advanced settings can set the start time, a timeout for devices that are offline, and an email to the AirLink account when the operation completes or times out. Click Change Offer.

Pre-paid plans are not changed from this screen. For those, submit a purchase order through your Semtech partner.

Alert rules​

Alert rules are created under Configure > Alert Rules. Click Create. A template pre-fills the conditions. You can change those values and add conditions. Set a name and a description, add one or more actions, and click Save.

Actions on the rule:

  • Send an email. Company users appear in the To field. The preview uses the alert name and description. The message includes a link to the system monitoring details.
  • Call a callback URL. One or more URLs are called when the alert is raised.
  • System suspend. No extra parameter. What suspension does is on States and operations and Suspend and restore.
  • Changing offer. Select the Service plan to apply when the alert is raised. On screen this action is labeled with Offer.
  • Apply label. The label is added when the alert is raised and removed when the alert clears.

Move one system to a larger bundle​

This rule changes one system to the next data-bundle size when that system passes its allotment. It does not change the whole pool.

1

Start from the template

Create a rule from the Usage limit exceeded template.

2

Set the conditions

Add a condition System is…, choose Offer, and select the current bundle. Set the monthly data condition to that bundle’s size. Both conditions are required so the rule runs only while the system is still on the smaller bundle.

3

Set the action

Add Change offer and choose the next-size bundle. Name the rule for that bundle size and click Save.

Change the Service plan when usage appears in the deployment country​

The current manual’s example activates factory test devices on the Pay per use Test Ready offer, then moves a device to the 10MB US bundle after usage in the United States.

1

Start from the template

Create a rule from Usage consumption from specified countries. Set the country condition. In the example, that country is the United States of America.

2

Keep the rule from repeating

Add a second condition that the system is still on the factory Service plan (in the example, Pay per use Test Ready offer). After the move to the 10MB US bundle, the rule no longer matches.

3

Change the plan

Add Change offer and select the deployment Service plan (in the example, the 10MB US bundle). An email action is optional. Click Save.

Usage after the change counts on the new Service plan. The bundle size is re-evaluated at the start of the next month from the number of SIMs then on that plan. The alert is raised when usage arrives from a listed country, and it clears when the Service plan change succeeds.

Pool usage​

On a bundle Service plan, data for the systems on that plan is pooled for the pricing zone. The Pool usage overage template raises an alert when monthly usage on that zone is nearing the pool (80%) or has reached it (100%). Past that level, more usage in the same month is overage. Usage in another zone is also overage, even when the pool itself is not full. The template applies to commercial Service plans.

Create the rule, select the Service plan, choose 80% or 100%, and optionally add an email. The alert is shown on the Service plan. From the alert you can open the systems activated on it.

Cap usage​

To stop one device from consuming the bundle, create a rule from Usage Limit Exceeded. Adjust the service and the limit. You can add System is or System has label so the rule covers only some systems. Add the action Suspend. An email action is optional. The current manual’s example suspends systems with the label Test at 5MB of data for the current month.

Usage in a country you did not plan for​

A roaming template can allow countries outside the deployment. The current manual’s example enables RZT - Africa 1 - Advanced 2020-10 for South Africa, then suspends a device that uses any other country in that template.

Create a rule from Usage consumption from specified countries. List the countries that should suspend the system (in the example, every country in that template except South Africa). You can add a condition on the system, a label, or the Service plan that authorizes the template. Add Suspend, and an email if you want one. The alert is raised when usage arrives from a listed country, and it clears on the next usage outside that list.

Before the module attaches​

Enable and attach are separate from Activate.

For an SW Advanced SIM, turn on the SIM Application Toolkit (STK), set automatic network selection, and turn on GPRS/packet-data auto attachment. An SW Essentials SIM or an Enhanced Carrier Connectivity SIM has no extra module requirement of that kind. The PIN is disabled by default. Ask your support contact for the PIN if you enable it. The full module list is in the Sierra Wireless Device requirements document.

On the first start with an SW Advanced SIM, wait until the network scan finishes. That scan is on the order of 15 minutes. During it, do not send data, SMS, or voice, and do not reboot. Later starts are about 15 seconds for an SW Advanced SIM, and 1 to 2 minutes for a tailored SIM.

First attach is the radio step after activation.

LPWA data on an AirLink device​

Limiting how much an AirLink device reports is a communication setting. It is separate from activating the SIM. Open Configure communication.

On ES, GX, LS, LX, MP, and RV devices using LWM2M, the default is one check-in a day that sends only the heartbeat. The heartbeat asks AirVantage whether an operation is waiting. It is about 900 bytes. Heartbeat alone leaves much of the device view empty.

The usual setup also sends the Default Status Report (about 50 to 60 data points, such as signal strength and carrier). Heartbeat plus that report is about 2 kB. The shortest interval is every 15 minutes.

Datasets collect extra points, or a smaller set in place of the default report.

Approximate monthly use from the current manual:

Check-inHeartbeat onlyHeartbeat and default status report
Once a week3.6 kB8 kB
Once a day (default)27 kB60 kB
Once an hour648 kB1.44 MB
Four times an hour (maximum)2.6 MB5.76 MB

You can keep the heartbeat more frequent than the status report, and you can turn the default report off and send a dataset of only the points you need.

Merge an Enhanced Carrier Connectivity SIM with a router​

The SIM has to be in Inventory. During registration you select that SIM and the Service plan, and the registration activates the SIM on the bundle. Insert the SIM and record which router serial number it is in before you start. The registration steps, including the CSV columns, stay on the current manual: How to merge ECC SIM cards with an AirLink router at Registration.

After activation, configure the APN​

SW Advanced and SW Essentials SIM​

To know which APN to configure, once the SIM is activated, go to Systems > Details and check the authorized APN in the System Info widget. In the documented example, only internet.swir is authorized on the system and shall be configured on the device or module.

If your Service plan specifies a different APN, it will appear there and will have to be configured in your module with the same value.

Operator prose uses Service plan. The API field remains offer / offerId.

Enhanced carrier connectivity SIM​

APNs for Enhanced carrier connectivity SIMs are pre-defined and do not depend on the Service plan picked at activation:

AT&T-CC 4G US offernmrx11.com.attz
AT&T-CC 4G International offernmrxintl.com.attz

SW Advanced and SW Essentials alias Smart Connectivity. Enhanced carrier connectivity aliases Carrier+.

SMS short codes (Enhanced carrier connectivity)​

Enhanced carrier connectivity SIM only allows SMS from and to your application. For Mobile Originating SMS, program the device to send SMS to the carrier short code:

ProductShort code
AT&T-CC53340005
Verizon2183500292
T-Mobile3339
Rogers600000012

Messages sent to those short codes are transmitted to your application through AirVantage Cloud Connectors. For Mobile Terminated SMS, use the Send SMS action from the user interface or from the API.

Using SMS and Voice​

Smart Connectivity allows SMS and Voice from any other mobile number. Use the international format for the destination number: 00 or +, followed by the phone number without the first 0.

Enhanced carrier connectivity SIM only allows SMS from and to your application. Short codes are on the APN reference.
