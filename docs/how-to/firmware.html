ALMS How-to

Firmware

Firmware is its own job. Upgrading firmware does not activate a SIM subscription, and registering a router does not run this upgrade.

The files stay in the file library. This page is the procedure.

Before you begin​

The systems you will upgrade, of one device type
The firmware package for that type
A window when the device can connect

An ALEOS package can include the radio-module firmware. An AirPrime or programmable-modem upgrade is a campaign: one component, or both the application and the firmware. Write the hops down before you start. An older ALEOS version can need more than one hop to reach the target.

Upgrade​

1

Select the systems

Open Monitor > Systems. Select systems of the same type. Filter by label or firmware version, then tick the rows. The header tick selects the whole filtered list, not only the page on screen.

2

Choose the package

Click Upgrade Firmware. Pick a package already in My Apps, or search Public Apps the first time you use that revision. Searching by name and revision copies it into My Apps for the next run.

3

Run it in batches on a module campaign

For an AirPrime or programmable modem, label a first batch of about 10 devices that have communicated recently, then larger batches. Apply the upgrade, retry the failures, and write down what happened before you clean up the labels.

4

Let the device connect

By default the upgrade runs on the device’s next connection. You can schedule a later time. System Operations stays in progress until that connection finishes the operation.

Firmware packages for a named release stay on The Source. The HL78 firmware package is a module file. The AirLink LX60 package is a router file. Neither file is pasted here.

The full ALEOS screen sequence is How to upgrade firmware on my ALEOS gateways?. The module campaign sequence is How to upgrade Firmware on my AirPrime module or AirLink programmable modem?.
