Do not invent product labels. Do not promote specimen-only phrases.

Use these names​

  • Jobs: Activate SIMs · Order SIMs · Call the API · Register routers
  • API: Call the API (job) · API reference (/api) · Web Services API (H1) · API HTML chapters (nav)
  • APN: APN and SMS short codes (H1) · APN table (nav)
  • Activate / Enable / Attach: A connectivity subscription / Service plan decision. It is not enable and is not attach. A PIN, STK, or module feature switch. Observed network behaviour. It is not guaranteed by a queued operation.

Lexicon include (_partials/_lexicon.mdx) is on Activate SIMs, First SIM, States, and First attach. Not on Order SIMs or Register routers.

The left rail is the same tree on every screen: Quick start, Browse by product, Keep building, then Get started · Reference · Changelog. How-to and Understand are not extra land-ons; those destinations already sit in Quick start and Keep building.

Lexicon one-liner (include _partials/_lexicon.mdx):

Activate is a Service plan / subscription decision. Enable is a PIN, STK, or module feature switch. Attach is radio / packet attach on the module. A System in the API is not the same object as a SIM. Operator prose uses Service plan; the API keeps offer / offerId — map that once, do not rename the contract.

Operator who just received SIMs​

Order is its own job. After SIMs arrive, Activate is a separate job. Picking a Service plan moves the subscription out of Inventory; it does not enable PIN/STK and it does not attach the module. Configure the APN after activation. Call the API is a different door from the HTML chapters.
